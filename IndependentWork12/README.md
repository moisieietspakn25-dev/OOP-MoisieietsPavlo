# Самостійна робота №12 — LINQ ETL та аналітика продажів

Демонструється ETL-процес: Extract (формування набору продажів), Transform (фільтрація та нормалізація), Load (агрегація за товарами). Дані генеруються програмно, без зовнішніх файлів.

## Запуск
```powershell
dotnet run --project IndependentWork12
```
