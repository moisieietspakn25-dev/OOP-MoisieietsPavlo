# ЗВІТ
## до лабораторної роботи № 8
**Тема:** Поліморфізм та ієрархія класів у C#

### 1. Мета роботи

Ознайомитися з принципами об'єктно-орієнтованого програмування в C#, навчитися створювати ієрархію класів, використовувати віртуальні методи та їх перевизначення, а також закріпити навички застосування поліморфізму й колекцій об'єктів базового типу.

### 2. Постановка завдання

Реалізувати ієрархію класів для поліморфних сповіщень. Створити базовий клас Alert і три похідні класи: EmailAlert, SMSAlert та PushAlert. Кожен клас повинен мати конструктор для ініціалізації полів і власну реалізацію методу Trigger().

Продемонструвати поліморфізм за допомогою колекції об'єктів базового типу, викликати метод сповіщення для кожного об'єкта та вивести список усіх спрацьованих сповіщень і їх загальну кількість.

### 3. Хід роботи

Під час виконання лабораторної роботи було створено ієрархію класів для моделювання системи сповіщень.

Базовий клас **Alert** містить текст повідомлення та віртуальний метод Trigger(), який визначає загальну поведінку сповіщення.

На основі базового класу створено три похідні класи:

- **EmailAlert** — призначений для моделювання сповіщень електронною поштою. Містить адресу отримувача.
- **SMSAlert** — призначений для моделювання SMS-сповіщень. Містить номер телефону.
- **PushAlert** — призначений для моделювання push-сповіщень. Містить ідентифікатор застосунку.

У кожному похідному класі перевизначено метод Trigger(), який виводить повідомлення відповідно до типу сповіщення.

Для демонстрації поліморфізму створено колекцію List типу Alert, до якої додано екземпляри всіх трьох похідних класів. За допомогою циклу було виконано виклик методу Trigger() для кожного об'єкта.

Також реалізовано підрахунок загальної кількості сповіщень у колекції.

### 4. Результати виконання

Після запуску програми в консолі відображається список спрацьованих сповіщень трьох типів:

1. Email-сповіщення про оформлення замовлення.
2. SMS-сповіщення з кодом підтвердження.
3. Push-сповіщення про нове повідомлення.

Наприкінці роботи програма виводить загальну кількість сповіщень — **3**.

Результати демонструють, що для кожного об'єкта викликається відповідна реалізація методу Trigger(), незважаючи на те, що всі об'єкти зберігаються в колекції базового типу.

### 5. Висновок

Було продемонстровано принцип поліморфізму за допомогою колекції об'єктів базового типу, організовано виклик відповідних методів для різних типів сповіщень і реалізовано підрахунок їх загальної кількості.
