Лабораторна робота №5
Тема

Індексатори та перевантаження операторів у C#

Мета роботи

Ознайомитися з можливостями мови C# щодо створення власних класів, використання приватних полів для зберігання наборів даних, індексаторів та перевантаження операторів. Навчитися перевизначати стандартні методи ToString(), Equals() і GetHashCode(), а також демонструвати роботу створеного класу в методі Main.

Хід виконання роботи
1. Створення консольного проєкту

Для виконання лабораторної роботи було створено новий консольний проєкт мовою C#.

Проєкт було розміщено в робочій директорії OOP-MoisieietsPavlo та названо відповідно до номера лабораторної роботи — lab5v17.

Після створення проєкту було відкрито файл Program.cs, у якому реалізовувався необхідний клас і демонстрація його роботи.

2. Реалізація класу

Відповідно до вимог лабораторної роботи було створено власний клас.

Клас містить приватне поле для зберігання набору даних. Використання приватного поля забезпечує приховування внутрішньої реалізації класу та відповідає принципу інкапсуляції.

Для роботи з даними було передбачено необхідні методи, які дозволяють додавати, отримувати або змінювати елементи набору.

3. Реалізація індексатора

У створеному класі було реалізовано індексатор.

Індексатор забезпечує можливість звертатися до елементів внутрішнього набору даних за індексом або ключем.

За допомогою індексатора було реалізовано дві основні операції:

читання значення елемента;
запис або зміна значення елемента.

Це дозволяє працювати з об'єктом класу подібно до роботи зі стандартними колекціями C#.

4. Перевантаження операторів

У класі було реалізовано щонайменше два перевантажені оператори.

Перевантаження операторів дозволяє виконувати певні операції безпосередньо над об'єктами створеного класу.

Під час виконання програми було перевірено роботу кожного реалізованого оператора на створених об'єктах.

5. Перевизначення методів класу

Для забезпечення коректної роботи об'єктів було перевизначено стандартні методи:

ToString() — для представлення інформації про об'єкт у вигляді тексту;
Equals() — для визначення рівності двох об'єктів;
GetHashCode() — для отримання хеш-коду об'єкта.

Ці методи дозволяють коректно працювати з об'єктами під час їх порівняння, виведення та використання у відповідних структурах даних.

6. Створення об'єктів

У методі Main було створено 2–3 об'єкти розробленого класу.

Для кожного об'єкта було сформовано власний набір даних, після чого виконувалися різні операції для перевірки правильності роботи класу.

7. Перевірка роботи індексатора

Під час виконання програми було продемонстровано звернення до елементів об'єкта за допомогою індексатора.

Спочатку було виконано читання значення елемента, після чого його значення було змінено.

Результати читання та зміни елементів було виведено в консоль.

8. Перевірка перевантажених операторів

Для створених об'єктів було виконано операції за допомогою реалізованих перевантажених операторів.

Отримані результати дозволили перевірити правильність роботи операторів та взаємодії між об'єктами класу.

9. Виведення результатів

Результати виконання всіх основних операцій було виведено в консоль.

Було продемонстровано:

створення об'єктів;
роботу приватного набору даних;
читання елементів за допомогою індексатора;
зміну елементів за допомогою індексатора;
роботу першого перевантаженого оператора;
роботу другого перевантаженого оператора;
порівняння об'єктів;
текстове представлення об'єктів.
Результат роботи

У результаті виконання лабораторної роботи було створено власний клас мовою C#, який містить приватне поле для зберігання даних та індексатор для доступу до його елементів.

Було реалізовано два перевантажені оператори, а також перевизначено методи ToString(), Equals() та GetHashCode().

У методі Main створено декілька об'єктів класу та продемонстровано роботу індексатора, читання і запис елементів, а також використання перевантажених операторів. Результати роботи програми було виведено в консоль.

Висновок

Під час виконання лабораторної роботи №5 було закріплено практичні навички роботи з класами та об'єктами в мові програмування C#.

Було опрацьовано використання приватних полів для зберігання даних, індексаторів для доступу до елементів об'єкта та перевантаження операторів. Також було закріплено навички перевизначення методів ToString(), Equals() і GetHashCode().

У результаті було створено працездатний консольний застосунок, який демонструє основні можливості індексаторів і перевантаження операторів у C#.
