# Самостійні роботи №8–15 — C#

Кожна робота розташована в окремій папці. Для №8 та №9 структура уточнена за методичними PDF.

| Робота | Тема |
|---|---|
| 8 | Узагальнений FIFO Cache та xUnit-тести (`IndependentWork7`, `IndependentWork7.Tests`) |
| 9 | Dictionary/HashSet: аналіз open-source, кеш метаданих, теги, пошуковий індекс |
| 10 | CollectionUtils: Map, MaxBy, Filter, ForEach |
| 11 | Inverted Index: токенізація та пошук AND/OR |
| 12 | LINQ ETL та аналітика продажів |
| 13 | LINQ vs PLINQ, Stopwatch і потокобезпечність |
| 14 | Polly: Retry та Timeout |
| 15 | Власна RetryPolicy з backoff і jitter |

Для кожного проєкту використовується .NET 8. Результати вимірювань і фактичний консольний вивід потрібно отримати запуском у локальному середовищі.
