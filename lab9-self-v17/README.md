# lab9-self-v17

Самостійна робота №9 — узагальнені методи обробки колекцій на C#.

## Реалізовані методи

- `Map` — перетворення елементів.
- `Filter` — фільтрація.
- `Reduce` — згортання колекції.
- `ForEach` — виконання дії для кожного елемента.

## Запуск

Потрібен встановлений .NET SDK.

```powershell
dotnet build
dotnet run
```
