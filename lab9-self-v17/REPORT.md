# Звіт до самостійної роботи №9

**Тема:** Реалізація узагальнених методів обробки колекцій.

**Мета:** Навчитися створювати узагальнені методи для обробки колекцій та використовувати делегати `Func` і `Action`.

## Завдання

Реалізувати статичний клас `CollectionUtils` із чотирма методами:
1. `Map` — перетворення кожного елемента колекції.
2. `Filter` — відбір елементів за умовою.
3. `Reduce` — згортання колекції до одного результату.
4. `ForEach` — виконання дії для кожного елемента.

## Хід роботи

1. Створено консольний проєкт мовою C#.
2. Реалізовано статичний клас `CollectionUtils`.
3. Створено клас `Product` для опису товарів.
4. Підготовлено список із десяти товарів.
5. Продемонстровано роботу методів `Map`, `Filter`, `Reduce` та `ForEach`.
6. Перевірено запуск програми.

## Результат

Програма виводить назви товарів, знаходить товари дорожчі за 2000 грн, обчислює загальну вартість складських залишків і показує товари, кількість яких менша за п'ять одиниць.

## Висновок

Під час виконання роботи закріплено навички використання узагальнень, делегатів `Func` та `Action`, а також створення власних методів обробки колекцій у C#.
