# Контрольні запитання — самостійна робота №9

1. **Переваги generic-колекцій:** типобезпека на етапі компіляції, відсутність зайвого boxing/unboxing для значущих типів, повторне використання алгоритмів.
2. **Dictionary і HashSet:** Dictionary застосовують для пошуку значення за ключем; HashSet — для унікальних елементів і швидкої перевірки належності.
3. **IEqualityComparer<T>:** задає правила Equals і GetHashCode. Несумісні реалізації можуть порушити пошук і унікальність; коректний comparer також визначає регістронезалежне порівняння рядків.
4. **Dictionary<string, HashSet<int>>:** словник швидко знаходить термін, а HashSet зберігає унікальні ID документів і підтримує перетин для пошуку всіх слів.
