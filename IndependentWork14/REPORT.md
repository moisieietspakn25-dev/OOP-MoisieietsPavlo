# Звіт — самостійна робота №14

У проєкті використано Polly ResiliencePipeline. Сценарій Retry повторює операцію після тимчасових помилок із експоненційним збільшенням затримки. Сценарій Timeout обмежує тривалість операції та обробляє TimeoutRejectedException. Для підтвердження результату необхідно зберегти фактичний вивід консолі після запуску.
