## 2. Теоретичні відомості

Індексатори дозволяють звертатися до даних об’єкта так само, як до елементів масиву або словника. Вони забезпечують зручний доступ до внутрішніх колекцій класу.

Перевантаження операторів дає змогу визначати власну поведінку стандартних операторів, наприклад додавання та порівняння, для об’єктів користувацьких типів.

Методи ToString(), Equals() і GetHashCode() використовуються для представлення об’єктів у вигляді рядка, порівняння об’єктів та отримання їхніх хеш-кодів.

## 5. Контрольні запитання

**1. Що таке індексатор і для чого він використовується?**

Індексатор — це спеціальний член класу, який дозволяє звертатися до даних об’єкта за індексом або ключем, використовуючи квадратні дужки.

**2. Яка різниця між індексатором та звичайною властивістю?**

Звичайна властивість зазвичай надає доступ до одного значення, а індексатор дозволяє отримувати або змінювати елементи залежно від переданого індексу чи ключа.

**3. Які оператори можна перевантажувати в C#?**

У C# можна перевантажувати багато операторів, зокрема арифметичні (+, -, \*, /), оператори порівняння (==, !=, >, <), а також деякі логічні та побітові оператори. Можливість перевантаження залежить від правил мови.

**4. Чому при перевантаженні == та != необхідно також перевизначити Equals() та GetHashCode()?**

Це забезпечує узгоджену поведінку порівняння об’єктів. Об’єкти, які вважаються рівними за Equals(), повинні мати однакові хеш-коди, що важливо для коректної роботи колекцій, які використовують хешування.

**5. Як індексатори підвищують читабельність коду?**

Індексатори дозволяють працювати з даними об’єкта за допомогою зрозумілого синтаксису квадратних дужок. Це зменшує кількість додаткових методів доступу та робить код простішим для читання.
