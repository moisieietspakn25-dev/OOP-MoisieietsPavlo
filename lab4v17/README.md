Мета роботи

Ознайомитися з можливостями об’єктно-орієнтованого програмування мовою C#. Навчитися створювати класи з приватними полями та публічними властивостями, реалізовувати перевірку коректності даних, використовувати статичні члени класу, індексатори та перевантаження операторів. Закріпити навички перевизначення методів ToString(), Equals() та GetHashCode().

Створення класу
Відповідно до завдання лабораторної роботи було реалізовано клас згідно з варіантом.

Клас містить приватні поля, які використовуються для зберігання внутрішнього стану об'єкта. Доступ до даних здійснюється через публічні властивості.

Для контролю правильності введених даних у властивостях реалізовано валідацію. Це дозволяє запобігати встановленню некоректних значень.

Реалізація властивостей
Для роботи з даними класу було створено публічні властивості.

Властивості забезпечують контрольований доступ до приватних полів. Під час встановлення значень виконується перевірка їхньої допустимості.

Якщо користувач намагається встановити некоректне значення, програма повідомляє про помилку або не дозволяє виконати таку операцію.

Використання статичного члена
У класі було реалізовано статичний член.

Статичний член належить самому класу, а не окремому об'єкту. Тому його можна використовувати без створення нового екземпляра класу.

За допомогою статичного члена було продемонстровано спільні для всіх об'єктів дані або функціональність.

Реалізація індексатора
Для класу було передбачено індексатор, оскільки він є доцільним для роботи з внутрішніми даними об'єкта.

Індексатор дозволяє звертатися до елементів об'єкта за індексом подібно до роботи з масивом.

Під час виконання програми було перевірено отримання та зміну значень за допомогою індексатора.

Перевантаження операторів
Однією з вимог лабораторної роботи було реалізувати перевантаження оператора.

Перевантажений оператор дозволяє виконувати відповідну операцію безпосередньо над об'єктами створеного класу.

Під час виконання програми було створено декілька об'єктів та продемонстровано результат роботи перевантаженого оператора.

Перевизначення стандартних методів
У класі було перевизначено стандартні методи:

ToString() — для зручного текстового представлення об'єкта; Equals() — для порівняння об'єктів; GetHashCode() — для формування хеш-коду об'єкта.

Перевизначення цих методів забезпечує коректну роботу об'єктів під час їх виведення, порівняння та використання в колекціях.

Демонстрація роботи програми
У методі Main було створено декілька об'єктів реалізованого класу.

Під час виконання програми було продемонстровано:

створення об'єктів класу; роботу публічних властивостей; перевірку валідації даних; використання статичного члена; роботу індексатора; використання перевантаженого оператора; виведення інформації про об'єкти; порівняння об'єктів за допомогою Equals(); отримання хеш-кодів об'єктів.

Результати роботи програми були виведені в консоль.

Результат роботи

У результаті виконання лабораторної роботи було створено консольний застосунок мовою C#, який демонструє основні можливості роботи з класами та об'єктами.

Було реалізовано приватні поля, публічні властивості з валідацією, статичний член, індексатор та перевантажений оператор. Також було перевизначено методи ToString(), Equals() та GetHashCode().

Програма успішно створює та обробляє декілька об'єктів класу, а результати виконання операцій відображаються в консолі.
