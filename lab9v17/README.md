# ЗВІТ
## до лабораторної роботи № 9
### Тема: Поліморфізм та обробка помилок у системі валідації даних

**Мета роботи:** навчитися створювати абстрактні класи та похідні класи, використовувати поліморфізм, реалізовувати перевірку вхідних даних і обробляти винятки в мові програмування C#.

### 1. Постановка завдання

Розробити поліморфну систему валідації даних. Створити абстрактний базовий клас `Validator` та три похідні класи: `EmailValidator`, `PhoneValidator` і `PasswordValidator`.

Реалізувати перевірку електронної пошти, номера телефону та пароля. Створити клас `NotificationService` для послідовного виконання перевірок, передбачити обробку помилок і продемонструвати роботу системи в головному методі програми.

### 2. Хід роботи

**2.1. Створення базового класу**

Було створено абстрактний клас `Validator`, який є основою системи валідації. Він містить властивість для збереження вхідних даних та абстрактний метод `Validate()`. Цей метод реалізується в кожному похідному класі відповідно до його призначення.

**2.2. Реалізація перевірки електронної пошти**

Клас `EmailValidator` перевіряє правильність формату електронної адреси. Перевіряється наявність імені користувача, символу @, доменного імені та доменної зони. Якщо вхідний рядок порожній, виникає виняток.

**2.3. Реалізація перевірки номера телефону**

Клас `PhoneValidator` перевіряє правильність номера телефону за українським форматом. Система підтримує номер із кодом країни +380, а також номер, що починається з нуля. Для перевірки видаляються пробіли, дужки та дефіси. Після цього перевіряється відповідність номера встановленому формату.

**2.4. Реалізація перевірки пароля**

Клас `PasswordValidator` перевіряє надійність пароля. Пароль повинен містити щонайменше вісім символів, одну велику літеру, одну малу літеру та одну цифру. Також передбачено перевірку коректності параметра мінімальної довжини пароля.

**2.5. Створення сервісу валідації**

Було створено клас `NotificationService`, який містить метод `SendAll()`. Метод приймає список об'єктів базового типу `Validator`, послідовно викликає метод `Validate()` для кожного об'єкта та виводить результат перевірки.

Для обробки помилок використовується механізм винятків `try-catch`. Завдяки цьому помилка під час перевірки одного елемента не перешкоджає обробці наступних елементів списку.

**2.6. Демонстрація роботи програми**

У головному методі `Main()` створено список об'єктів базового типу. До нього додано об'єкти всіх трьох похідних класів із правильними та неправильними вхідними даними.

Для демонстрації обробки помилок було передбачено порожній рядок електронної пошти. Програма повідомляє про помилку та продовжує перевірку решти об'єктів.

### 3. Результати роботи

У результаті виконання програми було перевірено різні типи вхідних даних.

- Електронна адреса `student@example.com` пройшла перевірку.
- Некоректна електронна адреса `wrong-email` не пройшла перевірку.
- Номер телефону `+380501234567` пройшов перевірку.
- Номер телефону `0501234567` пройшов перевірку після нормалізації формату.
- Пароль `StrongPass123` відповідає встановленим вимогам.
- Пароль `123` не відповідає вимогам надійності.
- Порожня електронна адреса спричинила виняток, який було перехоплено та оброблено.

Отже, програма демонструє перевірку даних, повідомлення про помилки та продовження роботи після виникнення винятку.

### 4. Висновок

Під час виконання лабораторної роботи було розроблено поліморфну систему валідації даних мовою C#. Створено абстрактний базовий клас `Validator` та три похідні класи для перевірки електронної пошти, номера телефону й пароля.

Було закріплено навички використання абстрактних класів, перевизначення методів, поліморфізму, колекцій об'єктів базового типу та обробки винятків. Також реалізовано централізований сервіс для виконання перевірок і продемонстровано обробку некоректних вхідних даних.

Поставлену мету лабораторної роботи досягнуто.
