# ЗВІТ
## до лабораторної роботи №15

**Дисципліна:** Об’єктно-орієнтоване програмування

**Тема:** LINQ у C#. Синтаксис запитів і методів. Аналіз продуктивності.

**Варіант:** 17

**Сценарій:** Управління курсами

### 1. Мета роботи

Ознайомитися з технологією LINQ у мові програмування C#, навчитися виконувати запити до колекцій об'єктів за допомогою синтаксису запитів і методів, використовувати фільтрацію, об'єднання, групування та сортування даних. Навчитися вимірювати час виконання запитів за допомогою Stopwatch та аналізувати продуктивність операцій LINQ.

### 2. Постановка завдання

Розробити програму для управління навчальними курсами.

Створити дві сутності:

- **Course** — курс, який містить ідентифікатор, назву, ідентифікатор викладача та максимальну кількість студентів.
- **Instructor** — викладач, який містить ідентифікатор, ім'я та спеціалізацію.

Заповнити колекції тестовими даними (не менше 10–20 елементів для кожної колекції).

Виконати чотири LINQ-запити, використовуючи синтаксис запитів і синтаксис методів, виміряти час виконання та проаналізувати отримані результати.

### 3. Опис реалізації

Для виконання лабораторної роботи було створено консольний застосунок мовою C#.

У програмі реалізовано дві основні сутності: Course та Instructor.

Для тестування створено:
- 20 викладачів із різними спеціалізаціями;
- 20 навчальних курсів із різною максимальною кількістю студентів.

Для обробки інформації використано технологію LINQ, яка дозволяє виконувати запити до колекцій об'єктів.

Для вимірювання часу виконання запитів використано клас Stopwatch із простору імен System.Diagnostics.
