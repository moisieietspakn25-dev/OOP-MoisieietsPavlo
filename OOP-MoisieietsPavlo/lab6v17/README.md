# ЛАБОРАТОРНА РОБОТА №6

## Тема

**Спадкування та поліморфізм у C#. Ієрархія класів**

## Мета роботи

Ознайомитися з принципами спадкування та поліморфізму в мові програмування C#. Навчитися створювати базові та похідні класи, використовувати конструктори базового класу, віртуальні методи, їх перевизначення за допомогою `override`, а також приховування методів за допомогою `new`.

## Варіант 17

Ієрархія класів:

**Plant → Tree → Flower**

Базовий клас **Plant** описує загальні характеристики рослин.

Похідний клас **Tree** описує дерева.

Похідний клас **Flower** описує квіти.

# Хід роботи

## 1. Створення базового класу Plant

У роботі було створено базовий клас **Plant**, який містить загальні властивості рослини.

Клас має такі характеристики:

* **Name** — назва рослини;
* **Height** — висота рослини.

Для зберігання даних використовуються приватні поля. Доступ до них здійснюється через публічні властивості.

Також у класі створено конструктор, який отримує назву та висоту рослини.

Для демонстрації поліморфізму в базовому класі створено віртуальний метод **Grow()**. Він описує загальний процес росту рослини та може бути перевизначений у похідних класах.

Крім того, базовий клас містить метод **GetPlantType()**, який використовується для демонстрації різниці між `override` та `new`.

---

## 2. Створення похідного класу Tree

Клас **Tree** успадковується від класу **Plant**.

Додатковою характеристикою дерева є:

* **TrunkDiameter** — діаметр стовбура.

Конструктор класу Tree приймає назву рослини, її висоту та діаметр стовбура. Для ініціалізації успадкованих властивостей використовується конструктор базового класу.

У класі Tree метод **Grow()** перевизначено за допомогою `override`. Реалізація описує ріст дерева.

Також клас має власний метод **ShedLeaves()**, який демонструє скидання листя деревом.

Для демонстрації ключового слова `new` у класі Tree створено власну версію методу **GetPlantType()**. Цей метод приховує однойменний метод базового класу.

---

## 3. Створення похідного класу Flower

Клас **Flower** також успадковується від класу **Plant**.

Додатковою властивістю класу є:

* **PetalColor** — колір пелюсток.

Конструктор Flower викликає конструктор базового класу для встановлення назви та висоти рослини.

Метод **Grow()** перевизначено за допомогою `override`. У ньому реалізовано власну поведінку росту квітки.

Також клас Flower має власний метод **Bloom()**, який демонструє процес цвітіння квітки.

---

# 4. Демонстрація поліморфізму

У методі Main було створено об'єкти класів Plant, Tree та Flower.

Для демонстрації поліморфізму об'єкти похідних класів було представлено через посилання на базовий клас Plant.

При виклику методу **Grow()** через посилання типу Plant виконується реалізація відповідного похідного класу.

Наприклад, для об'єкта Tree викликається реалізація Grow(), яка належить класу Tree, а для об'єкта Flower — реалізація класу Flower.

Таким чином, однакова назва методу може мати різну поведінку залежно від фактичного типу об'єкта.

---

# 5. Демонстрація різниці між override та new

У роботі було продемонстровано відмінність між ключовими словами `override` та `new`.

Метод **Grow()** є віртуальним у базовому класі Plant і перевизначений у Tree та Flower за допомогою `override`.

При зверненні до цього методу через посилання базового класу виконується метод фактичного похідного об'єкта. Це є прикладом поліморфізму.

Метод **GetPlantType()** у класі Tree оголошено з використанням `new`. Він приховує метод із базового класу, а не перевизначає його.

Тому результат виклику залежить від типу посилання:

* через посилання типу **Tree** викликається метод Tree;
* через посилання типу **Plant** викликається метод Plant.

Отже, `override` забезпечує поліморфну поведінку, а `new` лише приховує метод базового класу.
