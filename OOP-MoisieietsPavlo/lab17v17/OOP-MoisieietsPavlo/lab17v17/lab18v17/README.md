
# Лабораторна робота №18

## Тема
Власні винятки та патерн Result.

## Варіант
17 — Обробка конфігурації.

## Мета роботи
Навчитися створювати власні типи винятків та використовувати узагальнений клас Result<T> для контрольованої обробки помилок.

## Реалізація

У програмі реалізовано:

1. ConfigurationLoadException — власний тип винятку для помилок завантаження конфігурації.
2. Result<T> — узагальнений клас для представлення успішного результату або помилки.
3. ConfigurationService — сервіс для роботи з конфігураційним файлом.
4. LoadSetting(string key) — завантажує значення налаштування.
5. SaveSetting(string key, string value) — зберігає налаштування та повертає Result<bool>.

## Демонстрація роботи

Програма демонструє:
- Успішне збереження налаштувань.
- Перевірку некоректного ключа.
- Завантаження налаштувань із файлу.
- Обробку власного винятку через try-catch.
- Обробку Result<T> через IsSuccess та Error.

## Технології
- C#
- .NET SDK
- System.IO
- ООП

## Висновок

Під час виконання лабораторної роботи було створено власний виняток ConfigurationLoadException та узагальнений клас Result<T>.

Винятки доцільно використовувати для обробки непередбачених ситуацій, наприклад відсутності файлу конфігурації. Патерн Result<T> зручний для очікуваних помилок, наприклад некоректного ключа налаштування.

Таким чином, використання обох підходів дозволяє зробити програму більш зрозумілою, надійною та зручною для обслуговування.
