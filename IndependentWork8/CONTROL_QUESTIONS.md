# Контрольні запитання — самостійна робота №8

1. **Переваги Cache<TKey,TValue>:** один клас працює з різними типами ключів і значень без дублювання реалізацій; типи перевіряються компілятором.
2. **Dictionary + Queue:** Dictionary зберігає пари ключ-значення і дає доступ за ключем, Queue зберігає порядок додавання для FIFO-витіснення.
3. **Get і TryGetValue:** Get кидає KeyNotFoundException, коли відсутність ключа є помилкою для виклику. TryGetValue зручний, коли відсутність очікувана і її потрібно обробити без винятку.
4. **Критичні тести:** після заповнення кешу додати новий елемент і перевірити, що зник саме найстаріший; також перевірити, що інші елементи збережені, Count не перевищує capacity, а Get відсутнього ключа кидає виняток.
