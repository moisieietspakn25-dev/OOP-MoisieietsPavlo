## 1. Мета роботи

Ознайомитися з механізмами керування ресурсами в мові програмування C#. Навчитися реалізовувати інтерфейс `IDisposable`, використовувати патерн `Dispose` для звільнення керованих і некерованих ресурсів, а також дослідити роботу деструктора та збирача сміття.

## 2. Хід роботи

### 2.2. Реалізація класу PrinterConnection

Було створено клас `PrinterConnection`, який реалізує інтерфейс `IDisposable`.

Клас містить:

* приватні поля для збереження стану підключення та звільнення ресурсу;
* публічні властивості для назви принтера та перевірки стану підключення;
* конструктор для імітації підключення до принтера;
* метод `Dispose()` для звільнення ресурсів;
* захищений віртуальний метод `Dispose(bool disposing)`;
* деструктор, який викликає `Dispose(false)`.

### 2.3. Програмний код

```csharp
using System;

public class PrinterConnection : IDisposable
{
    private bool _disposed = false;
    private bool _isResourceAllocated;

    public string PrinterName { get; set; }
    public bool IsConnected { get; private set; }

    public PrinterConnection(string printerName)
    {
        PrinterName = printerName;
        _isResourceAllocated = true;
        IsConnected = true;

        Console.WriteLine(
            $"Підключено принтер: {PrinterName}");
    }

    protected virtual void Dispose(bool disposing)
    {
        if (!_disposed)
        {
            if (disposing)
            {
                Console.WriteLine(
                    "Звільнення керованих ресурсів");
            }

            if (_isResourceAllocated)
            {
                Console.WriteLine(
                    $"Відключення принтера: {PrinterName}");

                _isResourceAllocated = false;
                IsConnected = false;
            }

            _disposed = true;
        }
    }

    public void Dispose()
    {
        Dispose(true);
        GC.SuppressFinalize(this);
    }

    ~PrinterConnection()
    {
        Dispose(false);
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine("=== Використання using ===");

        using (PrinterConnection printer =
               new PrinterConnection("HP LaserJet"))
        {
            Console.WriteLine(
                $"Стан підключення: {printer.IsConnected}");
        }

        Console.WriteLine("\n=== Явний виклик Dispose ===");

        PrinterConnection printer2 =
            new PrinterConnection("Canon Pixma");

        printer2.Dispose();

        Console.WriteLine("\n=== Робота деструктора ===");

        PrinterConnection printer3 =
            new PrinterConnection("Epson L3150");

        printer3 = null;

        GC.Collect();
        GC.WaitForPendingFinalizers();

        Console.WriteLine("\nПрограму завершено.");
    }
}
```

### 2.4. Перевірка роботи програми

Під час виконання програми було перевірено три способи звільнення ресурсів.

1. **Використання `using`.** Після завершення блоку `using` автоматично викликається метод `Dispose()`, який звільняє ресурси.
2. **Явний виклик `Dispose()`.** Створений об'єкт принтера відключається після безпосереднього виклику методу `Dispose()`.
3. **Використання деструктора.** Для третього об'єкта метод `Dispose()` явно не викликається. Після запуску `GC.Collect()` і `GC.WaitForPendingFinalizers()` збирач сміття ініціює виконання деструктора, якщо об'єкт став недоступним.

## 3. Аналіз результатів

У ході виконання лабораторної роботи було реалізовано клас `PrinterConnection`, який демонструє використання інтерфейсу `IDisposable` та патерну `Dispose`.

Метод `Dispose(bool disposing)` забезпечує звільнення ресурсів. Параметр `disposing` дає змогу розрізняти звільнення керованих ресурсів під час явного виклику методу та звільнення некерованих ресурсів під час роботи деструктора.

Метод `GC.SuppressFinalize(this)` запобігає непотрібному виклику деструктора після явного звільнення ресурсів.

Варто враховувати, що в цій програмі підключення до принтера є імітацією, а не реальним системним підключенням або використанням некерованого ресурсу.
