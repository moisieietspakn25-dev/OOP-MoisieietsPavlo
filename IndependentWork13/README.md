# Самостійна робота №13 — LINQ та PLINQ

Порівняння послідовної та паралельної обробки 1, 5 і 10 мільйонів елементів. Використано Stopwatch та демонстрацію гонки даних з виправленням через Interlocked.

## Запуск
```powershell
dotnet run --project IndependentWork13 -c Release
```
Час залежить від процесора, навантаження системи та конфігурації збірки; у звіті потрібно записати власні результати запуску.
