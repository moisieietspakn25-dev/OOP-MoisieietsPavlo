### 3. Хід роботи

Під час виконання лабораторної роботи було створено консольний проєкт `lab13v17` на платформі .NET. Для реалізації функціональних операцій розроблено клас `FunctionalUtils`, який містить п’ять generic-методів.

**3.1. Метод Map**

Метод Map призначений для перетворення кожного елемента колекції за допомогою заданої функції. Результатом є новий список, елементи якого відповідають результатам перетворення. Роботу методу продемонстровано на списку цілих чисел, для яких було обчислено квадрати, а також на списку об’єктів студентів, з якого отримано список імен.

**3.2. Метод ForEach**

Метод ForEach виконує задану дію для кожного елемента колекції. Для передавання дії використовується делегат Action. Метод застосовано для виведення на екран імен студентів, числових значень та результатів сортування.

**3.3. Метод All**

Метод All перевіряє, чи задовольняють усі елементи колекції певну умову. Для передавання умови використовується делегат Predicate. Під час тестування перевірено, чи всі числа є додатними, а також чи мають усі студенти середній бал не нижче встановленого значення.

**3.4. Метод OrderBy**

Метод OrderBy призначений для сортування елементів за певним ключем. Ключ визначається за допомогою делегата Func. Метод використано для впорядкування студентів за середнім балом від найменшого до найбільшого. Для порівняння ключів передбачено обмеження типу, яке дозволяє використовувати інтерфейс IComparable.

**3.5. Метод Distinct**

Метод Distinct повертає список унікальних елементів, усуваючи повторення та зберігаючи порядок першої появи елементів. Його перевірено на списках рядків та цілих чисел.

### 5. Відповіді на контрольні запитання

**1. Що таке generic-методи і які переваги вони дають?**

Generic-методи — це узагальнені методи, які можуть працювати з різними типами даних. Їхні переваги полягають у повторному використанні коду, зменшенні дублювання та забезпеченні типобезпеки.

**2. Яка різниця між делегатами Func та Action?**

Func використовується для представлення функцій, які повертають значення. Action призначений для методів, які виконують певні дії та не повертають значення.

**3. Що таке функції вищого порядку? Наведіть приклади.**

Функції вищого порядку — це функції, які приймають інші функції як аргументи або повертають їх як результат. Прикладами є Map, Filter та ForEach.

**4. Навіщо потрібні обмеження generic-типів?**

Обмеження generic-типів визначають, які типи можна використовувати як параметри узагальненого методу. Наприклад, обмеження IComparable дає змогу порівнювати значення під час сортування.

**5. Як лямбда-вирази спрощують роботу з делегатами?**

Лямбда-вирази дають змогу коротко записувати функції та передавати їх як аргументи методів. Це робить код компактнішим, зрозумілішим і зручнішим для повторного використання.
